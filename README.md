# CODE TO MOTION · مكتبة الأدوات

موقع ورشة **CODE TO MOTION**، إعداد عبدالرحمن مصطفى ([@mostafaabodee8](https://x.com/mostafaabodee8)).
فيه مكتبة Skills ووكلاء وأوامر وبرومبتات، وأدوات تجربة لايف لـ Remotion، ودروس الورشة، ومشروع جاهز للتحميل.

## لوحة الإدارة

افتح `admin.html` (مثلًا `https://mostafaabodee6-dev.github.io/code-to-motion/admin.html`)، واكتب إيميل المشرف، ويوصلك رابط دخول.
- **الأعمال:** اللي يرفعه الحضور ينحفظ مخفي. تقدر تعتمده أو ترفضه أو تحذفه، وما يظهر في المعرض إلا المعتمد.
- **المشتركين:** إيميلات النشرة تشوفها أنت بس، وتنسخها أو تصدّرها CSV.
- **الورشة الجاية:** العنوان والموعد والرابط، وتظهر في الصفحة الرئيسية مع العد التنازلي.

البيانات محفوظة في Supabase (مشروع «Code to motion»)، والحماية مفعّلة في قاعدة البيانات نفسها (Row Level Security).
لإضافة مشرف ثاني، أضف إيميله لجدول `admins` من لوحة Supabase.
