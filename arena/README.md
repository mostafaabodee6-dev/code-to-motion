# Motion Arena | ساحة الموشن

محرر موشن يعمل من المتصفح وملحق مسابقات لورشة **CODE TO MOTION**. يوضع هذا المجلد في جذر مستودع الورشة ويعمل عند فتح `/code-to-motion/arena/` على GitHub Pages. يتوفر الاستوديو من دون حساب. يحتاج التحدي والمعرض والترتيب وشاشة البث إلى ترحيل قاعدة البيانات.

## التشغيل

من جذر مستودع الورشة، شغّل `py -m http.server 8766` على Windows أو `python3 -m http.server 8766` على macOS/Linux. افتح `http://localhost:8766/arena/`. يتطلب الاستخدام المستضاف HTTPS.  لا توجد خطوة بناء أو حزم npm للموقع. تُحمّل صفحات المسابقة مكتبة Supabase وإعدادات مشروع الورشة الموجودة أصلًا في جذر المستودع.

لتشغيل اختبارات المنطق، استخدم Node.js 20 أو أحدث وشغّل `node --test arena/tests/motion.test.mjs`. للتحقق من حفظ المشروع وتصدير الفيديو في متصفحك، افتح `/arena/tests/browser.html` واضغط Run browser check.

## إعداد المسابقة

1. تأكد أن المشروع هو Supabase الخاص بموقع الورشة، وأن الدالة الحالية `public.is_admin()` تقرأ صلاحيات المشرف بصورة صحيحة.
2. جرّب ترحيل [قاعدة البيانات](supabase/001_motion_arena.sql) في بيئة اختبار لها بنية المصادقة نفسها. بعد نجاح البروفة، طبّقه على مشروع الورشة.
3. أضف عنوان إعادة التوجيه الفعلي الذي ينتهي بـ `/arena/?arena_auth=1` إلى Supabase Auth → URL Configuration. اضبط إرسال البريد واختبره بحساب مشارك وبحساب المشرف. يقرأ الملحق إعداد المصادقة الحالي للورشة.
4. افتح `/arena/#/admin` بحساب مشرف الورشة، وانشر الفعالية، وأنشئ مسودة بعنوان وقواعد ومدة. الفعالية المبدئية بلا موعد مفترض.
5. أضف رابط الساحة إلى صفحة الورشة عندما تكون جاهزة. يمكن استضافة المجلد على GitHub Pages مباشرة.

اقرأ [دليل التشغيل والبروفة](docs/OPERATIONS.md) و[حالة التنفيذ](docs/STATUS.md) قبل استخدام المسابقة في بث فعلي.
